👨‍💻 About Me

I'm a B.Tech Computer Science student specializing in AI & ML, focused on building native Android applications with Kotlin, Jetpack Compose, and Firebase.

I enjoy working beyond the UI — designing clean architecture, state management, local persistence, networking, authentication, and AI-powered features that make apps feel production-ready.

📱 Android development is my primary focus.

🧩 Comfortable with MVVM, Clean Architecture, Repository Pattern, StateFlow, Room, Retrofit, and Hilt.

🤖 Exploring AI integration in Android apps using Gemini/Firebase AI and practical ML workflows.

💾 Interested in offline-first architecture, reliable sync, and maintainable code.

🚀 Currently building PrepPilot, an AI-powered mock-interview platform.

🎯 Goal: grow as an Android Developer and build real-world, production-quality applications.
